# Data inputs

Raw and genome-scale input data are not tracked in Git. Obtain them from the accessions listed in the main `README.md` or from the authorized project storage location.

Expected input categories include:

- *Cancer borealis* genome assembly FASTA files;
- STG15 paired-end RNA-seq FASTQ files;
- protein evidence used for BRAKER or EGAPx;
- RepeatMasker repeat libraries;
- DIAMOND reference protein databases;
- BUSCO lineage datasets; and
- eggNOG-mapper databases.

For each manuscript-associated input, record the accession, release, file size, and SHA-256 checksum. Never commit human-readable credentials, access tokens, protected data, or private storage paths.
